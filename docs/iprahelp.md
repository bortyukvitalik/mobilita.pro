# iprahelp.ru — лендинг-диагностика ИПРА/ТСР (лид-магнит MDCPlanet)

## Суть

Бесплатный сайт-помощник: помогает инвалидам и их семьям разобраться с ИПРА и получить ТСР по государственной программе. После диагностики → лид уходит в MDCPlanet. Нет прямой коммерции. Позиция: социальная миссия фонда «Шагать не просто».

**Hypothesis core:** Если помочь человеку понять что ему положено по закону → он доверяет нам как эксперту → приходит за покупкой в MDCPlanet.

## Роль в экосистеме

```
Органический трафик (SEO/Telegram/Яндекс)
        ↓
  iprahelp.ru  ← ДИАГНОСТИКА (бесплатно)
        ↓ лид (имя + телефон + профиль ТСР)
  MDCPlanet.com ← ПРОДАЖИ
        ↓
  Электронный сертификат СФР (оплата)
```
